# RSVP Speed Reader Web App

A clean and modern RSVP (Rapid Serial Visual Presentation) speed-reading web application designed to help you read faster and maintain focus.

## Features
- **File Upload:** Upload your own `.txt` or `.epub` books.
- **Adjustable Speed:** Control your reading speed in Words Per Minute (WPM).
- **Smart Pacing:** Automatically adjusts reading speed for longer words and punctuation to improve comprehension.
- **Focus Mode:** Minimalist UI to keep you focused on the text.
- **Fully Client-Side:** All processing happens in your browser. Your files are not uploaded to any server.
